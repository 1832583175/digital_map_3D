大屏数据控制台 / Xinjiang Dashboard

服务 - 实时通道 - 在线大屏 0 数据更新 -

数据集编辑器 PUT /api/dataset —— 保存并推送后，大屏自动更新

说明：只改需要的字段即可（PATCH 语义，未传的保持原值）。可用字段：site（标题/KPI）、 map（投影参数）、cities（三维柱）、points（散点/监测点）、 districts（区县分类）。cities.name 必须与 geojson 地名一致。

顶部指标快捷推送 POST /api/kpi · 大屏原地滚动数字，不刷新

实时日志 GET /api/stream

命令行推送示例

局部更新城市数据：
curl -X PATCH http://localhost:8787/api/dataset -H "Content-Type: application/json" -d "{\"cities\":[{\"name\":\"乌鲁木齐市\",\"value\":500}]} "

高频推送指标：
curl -X POST http://localhost:8787/api/kpi -H "Content-Type: application/json" -d "{\"index\":0,\"value\":21000}"
