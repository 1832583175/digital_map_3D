# COS + 备案域名 · 完整方案（手把手）

> 目标：网站跑在腾讯云 COS 上、用自己已备案的域名访问、国内秒开。
> 这是「国内正式上线」的正规军路线，但**时间成本 2~4 周、有隐性年费**，动手前请先读第零节。

---

## 零、先看清楚这条路的真实代价（3 个硬事实）

### 硬事实 1：COS 本身不能用来备案

腾讯云规定：**发起 ICP 备案必须持有一台符合条件的云服务器**：

- 中国大陆地域
- **包年包月**计费，购买时长 **≥3 个月**（含续费），备案期间剩余有效期 ≥1 个月
- CVM 或 轻量应用服务器（Lighthouse）都行；按量计费、试用机、HAI 均不支持

COS / CDN / 静态托管 **不在可备案资源列表里**。
所以标准玩法是：**买一台最低配轻量服务器拿备案资格（备案专用，网站实际跑在 COS 上）**，这也是个人站长的普遍做法。

### 硬事实 2：备案下来后，服务器不能立刻退

接入商会定期核查「备案 ↔ 云资源」关联。**备案专用的服务器到期不续费，可能被取消接入 → 备案随之注销**。
这意味着这台最低配服务器是**长期持有成本**，不是一次性投入。

### 硬事实 3：备案期间域名必须处于「打不开」状态

管局要求备案审核期间网站不能访问、域名不能解析到任何地方。
**好消息**：如果你已经把站放在 GitHub Pages 上了，备案期间可以继续用 GitHub Pages 地址（只要域名本身不解析就行），两者不冲突。

### 总账（以 2026 年常见价格估，以购买页为准）

| 项目 | 费用 | 说明 |
|---|---|---|
| 域名 `.com` / `.cn` | 约 55~80 元/首年，续费 80~100 元/年 | 腾讯云注册 |
| 轻量服务器 2C2G（≥3 个月） | 约 100~200 元 | 活动价可能更低；**必须包年包月 ≥3 个月** |
| 备案 | **免费** | 腾讯云备案不收费 |
| COS 存储 + 流量 | 约 1~3 元/月（低流量） | 4MB 的站，1000 次访问 ≈ 2 元 |
| HTTPS 证书 | **免费**（腾讯云 DV 证书，1 年期） | |
| **合计** | **首年约 200~400 元 + 每月几块钱流量** | 其中大头是那台备案专用服务器 |

### 时间线

```
第 1 天        买域名 + 买轻量服务器（当天可完成）
第 2~4 天      域名实名审核通过
第 4 天        提交 ICP 备案
第 5~7 天      腾讯云初审（可能来电话核实）
第 1~3 周      管局审核（各省快慢不同，快则三五天，慢则两周+）
第 2~4 周      拿到备案号 → 当天即可绑 COS 上线
上线后 30 天内  办公安备案（别忘！）
```

---

## 一、买域名（10 分钟动手 + 1~3 天等待）

1. 打开 <https://buy.cloud.tencent.com/domain>
2. 搜索想要的域名，个人用推荐 `.com` 或 `.cn`（`.cn` 首年常有优惠）
3. 加入清单 → 结算，**持有人信息填你自己的真实姓名和身份证号**（和腾讯云账号实名一致最省事）
4. 支付后进 **控制台 → 域名注册 → 我的域名**，对新域名点「实名认证」，上传身份证，提交
5. 等审核通过（一般几小时到 1~3 天），状态变为「已实名」

**注意事项**：
- 域名所有人和备案主体一致（个人备案 = 域名在你个人名下），否则备案会被驳回
- 刚注册的域名别急着提备案，先等实名过审；个别情况管局要求注册满 3 天
- 域名注册商必须是境内的（腾讯云注册天然满足）；在 GoDaddy 等境外商注册的域名不能在腾讯云备案

---

## 二、买一台「备案专用」服务器（10 分钟）

1. 打开 <https://cloud.tencent.com/product/lighthouse> → 立即购买
2. 配置按最低来（够备案就行）：

| 配置项 | 选什么 |
|---|---|
| 地域 | **中国大陆任选**（广州/上海/北京均可，就近） |
| 镜像 | 随便（如 Ubuntu Server 22.04 LTS），这台服务器基本不干活 |
| 套餐 | 最低配 2C2G 即可 |
| 购买时长 | **≥3 个月**（硬性要求；建议直接买 1 年，省得中途到期断备案） |

3. 支付完成，控制台能看到这台机器即可，**不用登录、不用装任何东西**

> 同样这台机器以后也可以拿来跑别的（它就是台真服务器）。但记住：别删、别到期。

---

## 三、提交 ICP 备案（填表 30 分钟 + 审核 1~3 周）

推荐用**微信小程序**操作，全程手机拍照+人脸识别，比 PC 端快：

1. 微信搜索小程序「**腾讯云网站备案**」，或打开 PC 端 <https://console.cloud.tencent.com/beian>
2. 开始备案 → 主体类型选「**个人**」（你是个人实名账号）
3. 按提示填写，几个容易填错的地方：

| 字段 | 怎么填 |
|---|---|
| 身份证/人脸核身 | 按提示拍，光线好一点一次过 |
| 备案云资源 | 选你那台**轻量应用服务器**（列表里会直接出现，选中即可） |
| 网站名称 | **个人备案的雷区**：不能用「XX平台」「XX系统」「中国/国家」这类词；建议「XX的个人作品集」「XX个人主页」这类 |
| 网站内容 | 选「其他」或「博客/个人空间」 |
| 网站语言 | 简体中文 |
| 域名 | 填刚买的域名 |
| 网站底部悬挂备案号 | 选「是」 |

4. 提交后腾讯云初审 **1~2 天**，可能打电话核实（如实回答：个人网站、展示类、无经营内容）
5. 初审通过转管局，**1~3 周**出结果
6. 通过后短信下发两样东西：**备案号**（如 `粤ICP备2026XXXXXX号-1`）和**备案密码**（保管好，以后转接入商要用）

> 审核期间：域名不要解析、不要开任何能访问的网站；买好的服务器保持运行即可。
> 驳回不可怕，按驳回理由改了重新提就行，大多数人会经历 1 次驳回（常见原因：网站名称不合适、照片模糊、地址写法不规范）。

---

## 四、等备案期间：把 COS 和网站全部准备好（30 分钟）

备案要等 1~3 周，这段时间把下面的事全部做完，备案号一下来当天就能上线。

### 4.1 建桶 + 传文件 + 开静态网站

完整步骤照着 [`COS部署指南.md`](COS部署指南.md) 的第二、三、四节做，这里只强调差异点：

| 配置 | 备案路线的选法 |
|---|---|
| 地域 | **中国大陆**（广州/上海/北京均可） |
| 访问权限 | 公有读私有写 |
| 静态网站 | 开启，索引/错误文档都填 `index.html` |
| 绑自定义域名 | **先不做**（域名还没备案，绑了也过不了校验，等第五节） |

### 4.2 把页脚备案号占位改好（管局抽查必查项）

我已经在 `index.html` 里预置了备案号占位（页面左下角小字，默认隐藏）：

```html
<a id="icp" href="https://beian.miit.gov.cn/" ... style="display:none; ...">
    粤ICP备XXXXXXXX号-1
</a>
```

备案通过后，把 `粤ICP备XXXXXXXX号-1` 换成你的真实备案号，再把 `display:none` 删掉（或改成 `display:block`），重新构建上传即可。

> 大屏类网站没有传统页脚，这个占位是「左下角固定定位的半透明小字」，不影响视觉效果，但管局/公安抽查时能看到。

### 4.3 （可选）备案期间先用 GitHub Pages 顶着

按 [`GitHub自动部署指南.md`](GitHub自动部署指南.md) 把站推上去给同事/客户看演示。**注意：只能用 `xxx.github.io` 地址，别把自己域名解析上去**，否则违反「备案期间网站不可访问」。

## 五、备案通过：上线四步（30 分钟）

### 5.1 COS 绑自定义域名

存储桶 → 域名与传输管理 → 自定义源站域名 → 添加域名：

| 配置项 | 填什么 |
|---|---|
| 域名 | `dash.yourdomain.com`（或裸域 `yourdomain.com`） |
| 源站类型 | **静态网站源站** |
| 强制 HTTPS | 先关，证书好了再开 |

记下生成的 **CNAME 值**。

### 5.2 配 DNS 解析

域名控制台（DNSPod）→ 你的域名 → 添加记录：

| 记录类型 | 主机记录 | 记录值 |
|---|---|---|
| CNAME | `dash`（或 `@`） | 5.1 复制的 CNAME 值 |

### 5.3 配 HTTPS

「自定义源站域名」→ 绑定证书 → 申请腾讯云**免费 DV 证书**（几分钟签发）→ 绑定 → 打开「强制 HTTPS」。

### 5.4 打开备案号显示并上传

1. 改 `index.html`：填真实备案号 + 显示元素（见 4.2）
2. `npm run build`
3. 按 [`COS部署指南.md`](COS部署指南.md) 第三节的任一方式重新上传 `dist/`（推荐 coscmd，一条命令）
4. 浏览器打开 `https://dash.yourdomain.com` 验收：大屏正常、左下角有备案号小字、地址栏有锁

---

## 六、上线后 30 天内：办公安备案（很多人漏掉）

ICP 备案通过后 **30 天内**，必须再到公安系统做一次备案（全国联网备案，和 ICP 备案是两回事）：

1. 打开 <https://beian.mps.gov.cn> → 注册账号（用网站负责人身份）
2. 「用户备案」→ 新增网站备案，填网站信息 + 上次拿到的 **ICP 备案号**
3. 审核通过后得到一个 **公安备案号**（如 `粤公安网备 440XXXXXXXXX号`），按短信要求挂到网站底部（可以和 ICP 备案号并排，中间加个"·"）
4. 顺带在页脚加上公安备案标识图片（平台会给你链接），规范做法是两个备案号都挂在左下角

> 不办公安备案不影响访问，但属于违规，被抽查到会通知限期整改。做齐只要 10 分钟，别拖。

## 七、以后的日常更新

```bash
cd xinjiang-dashboard
# 1. 改代码
npm run build
# 2. 上传（coscmd 一条命令）
coscmd upload -r dist/ /
```

记得给 `index.html` 单独设 `Cache-Control: no-cache`（COS 部署指南第六节），否则用户刷新看不到新版。

服务器那边：**每年记得续费轻量服务器**（设个自动续费最稳），备案号就一直在。

## 八、常见坑排查表

| 现象 | 原因 | 解决 |
|---|---|---|
| 备案被驳回：网站名称不合适 | 用了「平台/系统/中心」等词 | 换成「XX的个人作品集」这类中性名 |
| 备案被驳回：主体信息不符 | 域名所有人和备案人不一致 | 域名过户或换域名重新注册 |
| 备案被驳回：照片/视频不合格 | 身份证反光、人脸识别光线差 | 重拍重传 |
| 绑自定义域名提示「域名未备案」 | 备案还在管局审核中 | 等短信下发备案号再绑 |
| 绑好了域名但打不开 | DNS 还没生效 / CNAME 填错 | `nslookup dash.yourdomain.com` 核对 |
| 打开就下载文件 | 用了 COS 默认域名 | 必须走自定义域名（本文 5.1） |
| 证书绑定后访问报证书不匹配 | 证书域名和访问域名不一致 | 重新申请覆盖当前子域名的证书 |
| 备案被注销 | 服务器到期没续费，接入被取消 | 自动续费；或备案信息变更到新服务器 |
| 页面打开报 MIME 错误 | Content-Type 不对 | 见 COS 指南第十节 |

## 九、和另两条路线怎么选

| | GitHub Pages | COS + 未备案（境外桶） | **COS + 备案域名（本篇）** |
|---|---|---|---|
| 上线时间 | 15 分钟 | 30 分钟 | **2~4 周** |
| 花费 | 0 | 0 | 首年 200~400 元 |
| 国内速度 | 慢/不稳 | 中等 | **最快** |
| 能否挂广告/正式运营 | 灰色 | 灰色 | **合规** |
| 适合 | 演示、作品集 | 临时给人看 | **正式对外、给客户交付** |

结论：**给客户交付或长期运营 → 本篇路线；自用演示 → GitHub Pages 足够。**
