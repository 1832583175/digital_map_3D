# 后端接入指南（数据推送）

> 大屏支持「无后端纯静态」和「接后端动态数据」两种模式。
> 不开后端时一切照旧（数据来自 `src/config/`），**开了后端就会自动连接**，无需要改任何代码。

## 一、架构一览

```
┌──────────────────────────┐        ┌─────────────────────────────┐
│  数据后端 (server/, :8787) │ ─SSE──▶│  大屏页面 (:8090 / 静态部署)   │
│  数据控制台  http://…/    │ ◀──────│  src/services/live.js        │
│  REST  /api/dataset      │  HTTP  │  启动拉取 + 实时订阅           │
└──────────────────────────┘        └─────────────────────────────┘
```

- **零依赖**：后端只用 Node 内置模块，`node server/index.js` 直接跑，不需要 `npm install`
- **持久化**：数据存在 `server/data/dataset.json`，重启服务不丢
- **推送机制**：
  - `POST /api/kpi` → 顶部指标**原地数字滚动 + 发光脉冲**（适合高频，不刷新页面）
  - `PUT/PATCH /api/dataset` → 结构化数据变更 → 大屏短暂显示「数据同步中」后自动刷新（三维场景需要重建）

## 二、启动

```bash
# 方式一（推荐）：在大屏工程根目录
npm run api

# 方式二：直接跑
node server/index.js

# 自定义端口 / 开启写入鉴权
PORT=9000 API_TOKEN=mysecret node server/index.js
```

启动后：

| 地址 | 用途 |
|---|---|
| http://localhost:8787/ | **数据控制台**（网页上直接改数据、一键推送） |
| http://localhost:8787/dashboard/ | 大屏静态页（需先 `npm run build`，一个端口全搞定） |
| http://localhost:8787/api/health | 健康检查（含在线大屏数量） |
| http://localhost:8787/api/stream | 实时事件流（SSE） |

## 三、数据控制台（最省事的数据入口）

打开 `http://localhost:8787/`：

1. **顶部指标快捷推送**：右侧表格填新值 → 点「推送数值」→ 大屏数字滚动
2. **数据集编辑器**：左侧 JSON 直接改 → 点「保存并推送到大屏」→ 大屏自动刷新生效
3. **实时日志**：谁推了什么、当前几个大屏在线，一目了然
4. **恢复默认数据**：改乱了随时一键回滚（种子数据来自当前 `src/config`，可用 `npm run api:seed` 重新生成）

## 四、接口明细

### GET /api/dataset — 拉取全部数据

```json
{
  "version": 1,
  "updatedAt": "2026-11-04T04:44:07.698Z",
  "site":  { "title": "…", "subTitle": "…", "kpi": [{ "icon": "xiaoshoujine", "zh": "2024年生产总值", "en": "…", "value": 20534, "unit": "亿元" }] },
  "map":   { "projectionCenter": [84.946334, 42.188608], "projectionScale": 38, "flyLineCenter": [87.617733, 43.792818], "focusLabel": { "…": "…" }, "geojson": { "…": "…" } },
  "cities":    [{ "name": "乌鲁木齐市", "enName": "urumqi", "center": [87.6, 43.7], "centroid": [87.7, 43.7], "value": 408 }],
  "points":    { "scatter": [{ "value": 125, "lng": 87.0, "lat": 43.4 }], "monitor": [{ "…": "…" }] },
  "districts": ["天山区", "沙依巴克区", "新市区", "水磨沟区", "头屯河区"]
}
```

### PUT /api/dataset — 全量替换（未传的 section 保留原值）

```bash
curl -X PUT http://localhost:8787/api/dataset \
  -H "Content-Type: application/json" \
  -d @my-data.json
```

### PATCH /api/dataset — 局部更新（推荐，只传要改的）

```bash
# 只改标题
curl -X PATCH http://localhost:8787/api/dataset \
  -H "Content-Type: application/json" \
  -d '{"site":{"title":"新疆经济驾驶舱"}}'

# 只改城市柱数据（数组按整体替换）
curl -X PATCH http://localhost:8787/api/dataset \
  -H "Content-Type: application/json" \
  -d '{"cities":[{"name":"乌鲁木齐市","value":500},{"name":"喀什地区","value":460}]}'
```

### POST /api/kpi — 高频指标推送（大屏不刷新）

```bash
curl -X POST http://localhost:8787/api/kpi -H "Content-Type: application/json" -d '{"index":0,"value":21000}'
curl -X POST http://localhost:8787/api/kpi -H "Content-Type: application/json" -d '{"values":[21000,2600]}'
curl -X POST http://localhost:8787/api/kpi -H "Content-Type: application/json" -d '{"zh":"2024年生产总值","value":21000}'
```

### POST /api/dataset/reset — 恢复种子数据

### GET /api/stream — SSE 事件

| event | data | 大屏行为 |
|---|---|---|
| `hello` | `{clients, serverTime}` | 仅记录（连接时不回放数据，避免刷新循环） |
| `kpi` | `{kpi: [...]}` | 顶部数字滚动 + 发光 |
| `dataset` | `{dataset, by}` | 遮罩提示 → 整页刷新生效 |

## 五、让大屏连上后端（4 种方式，按优先级）

1. **控制台注入**：浏览器控制台 `window.__API_BASE__='http://192.168.1.10:8787'` 后刷新（临时调试）
2. **URL 参数**：`http://…/#/gdMap?api=http://192.168.1.10:8787`（写一次自动记住到 localStorage；`?api=off` 关闭）
3. **构建期环境变量**（部署推荐）：
   ```bash
   VITE_API_URL=http://192.168.1.10:8787 npm run build
   ```
4. **默认**：页面跑在 localhost 时自动连 `http://localhost:8787`；部署到服务器/静态托管时若 1-3 都没配，则**不连后端**（纯静态模式，避免无谓请求）

## 六、安全

- 未设 `API_TOKEN`：**只允许本机写**（远程写返回 403）
- 设了 `API_TOKEN=xxx`：所有写接口需带请求头 `x-api-token: xxx`
- CORS 已放开（大屏可能部署在别的域）；生产环境建议用 Nginx 反代同域，或收紧 `Access-Control-Allow-Origin`（改 `server/index.js` 一行）

## 七、常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 大屏控制台没有 `[live] 已从后端加载数据` | 后端没启动，或地址不对 → 用 `?api=` 指定 |
| 推送后大屏没反应 | 检查 `/api/health` 的 `dashboardClients` 是否 ≥1（SSE 被代理掐断时换直连） |
| 401 | 设了 `API_TOKEN` 但请求没带 `x-api-token` 头 |
| 403 | 未设 token 且从远程机器写 → 本机操作或设置 token |
| 400 未知字段 | 字段名拼错；可用字段：`site / map / cities / points / districts` |
| 推送 cities 后地图柱子没变 | 刷新后才会重建三维场景（推送 dataset 事件会自动刷）；确认 `name` 与 geojson 地名完全一致 |
| 想改初始数据 | 改 `src/config/` 后 `npm run api:seed` 重新生成种子 |
