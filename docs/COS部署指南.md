# 腾讯云 COS 静态托管 · 手把手部署指南

> 目标：把 `dist/` 目录（34 个文件，约 4MB）挂到公网，手机也能打开。
> 全程控制台点鼠标即可，不需要买服务器。

---

## 零、先看这三条硬约束（决定你要不要走这条路）

### ① 2024 年之后新建的存储桶，默认域名打不开网页

腾讯云对 2024-01-01 之后创建的桶做了安全管控：**用 COS 自带的默认域名访问任何文件，都会被强制下载，不能在浏览器里预览**。
服务端会强制加两个响应头：

```
x-cos-force-download: true
Content-Disposition: attachment
```

受影响的域名包括：存储桶默认域名、**静态网站域名**、全球加速域名。

结论：**新建的桶必须绑自定义域名才能真正当网站用**，官方文档原文是「访问默认域名会显著影响静态网站的索引文档与错误文档功能」。

### ② 绑自定义域名 = 要备案

- 存储桶在**中国大陆地域**（广州/上海/北京等）→ 域名**必须已完成 ICP 网站备案**
- 存储桶在**境外地域**（中国香港/新加坡等）→ 不用备案，域名注册好就能绑，但国内访问延迟高一些

### ③ 所以先做选择

| 你的情况 | 走法 | 体验 |
|---|---|---|
| 已有**已备案**域名 | 大陆地域 COS + 自定义域名 | ⭐ 最佳，国内秒开 |
| 有域名但没备案 | 中国香港地域 COS + 自定义域名（不备案） | 可用，国内访问 100~300ms |
| 没域名 / 不想备案 / 只想先看效果 | **别用 COS**，走 Cloudflare Pages 或 Netlify Drop | 免费、免备案、5 分钟上线 |

> 如果你只是想给自己或同事看效果，第三条才是「又省钱又方便」的答案。COS 的真正优势是**国内访问速度**和**依托腾讯云生态**（后面接 CDN、云函数、私有化）。
> 只有要正式对外、且面向国内用户时，才值得为它准备一个备案域名。

## 一、准备账号

1. 打开 <https://cloud.tencent.com> 注册账号
2. **完成实名认证**（个人身份证即可，没实名用不了 COS）
3. 控制台搜索「对象存储」→ 点击开通 COS 服务（免费开通）

---

## 二、创建存储桶

进入 [对象存储控制台](https://console.cloud.tencent.com/cos) → 左侧「存储桶列表」→ **创建存储桶**。

| 配置项 | 填什么 | 说明 |
|---|---|---|
| 名称 | `xinjiang-dashboard` | 只能小写字母/数字/短横线，全局唯一，被占用就换一个 |
| 所属地域 | `北京` 或 `广州`（有备案域名）/ `中国香港`（没备案） | **建完不能改**，想清楚再选 |
| 访问权限 | **公有读私有写** | 必须选这个，否则访客 403 |
| 版本控制 | 关闭 | 静态站用不上，开着占存储费 |
| 服务端加密 | 关闭 | 同上 |
| 内容分发网络 CDN | **先不勾** | 初期省事，后期需要加速再加 |
| 日志存储 | 关闭 | 省费用 |

创建后记下两个东西（后面要用）：

```
存储桶名称：xinjiang-dashboard-125xxxxxxxxx   ← 后面那串数字是你的 APPID
所属地域：ap-guangzhou
```

## 三、上传 dist 目录

**关键：传的是 `dist/` 里面的内容，不是 dist 这个文件夹本身。**
上传后桶根目录必须直接看到 `index.html`，不能是 `dist/index.html`。

### 方式 A：控制台拖拽（最简单，适合首次）

1. 点进存储桶 → 「文件列表」→ **上传文件**
2. 选「文件夹」，把 `xinjiang-dashboard/dist` 下的 **`assets`、`static`、`draco` 三个文件夹 + `index.html` + `favicon.svg`** 一起拖进去
3. 确认上传，等进度条走完（4MB 很快）

### 方式 B：COSBrowser 客户端（适合经常更新）

下载 [COSBrowser](https://cloud.tencent.com/document/product/436/11366) → 用 SecretId/SecretKey 登录 → 左侧本地打开 dist → 全选拖到右侧桶里。

### 方式 C：命令行（适合后期自动化）

```bash
pip install coscmd

# 配置（密钥在 控制台 → 访问管理 → API密钥管理 里创建）
coscmd config -a <SecretId> -s <SecretKey> \
              -b xinjiang-dashboard-125xxxxxxxxx \
              -r ap-guangzhou

# 上传整个 dist（注意 dist/ 后面这个斜杠，表示传内容不传目录）
cd xinjiang-dashboard
coscmd upload -r dist/ /
```

> 安全提醒：SecretKey 等于账号密码，别提交到 Git、别贴群里。建议在「访问管理」里建一个只有该桶读写权限的子账号来生成密钥。

## 四、开启静态网站

存储桶 → 左侧「基础配置」→ 拉到底「静态网站」→ **编辑**：

| 配置项 | 填什么 |
|---|---|
| 当前状态 | **开启** |
| 索引文档 | `index.html` |
| 错误文档 | `index.html` |
| 强制 HTTPS | **关闭**（后面在自定义域名那里开，这里开了容易和后面的配置打架） |

保存后会给你一个静态网站域名，形如：

```
xinjiang-dashboard-125xxxxxxxxx.cos-website.ap-guangzhou.myqcloud.com
```

⚠️ **现在点开它大概率是下载一个文件而不是显示网页**——这就是第 ① 条约束，正常现象，别怀疑自己配错了。继续往下走。

---

## 五、绑定自定义域名（必须做）

### 5.1 在 COS 里添加域名

存储桶 → 左侧「域名与传输管理」→「自定义源站域名」→ **添加域名**：

| 配置项 | 填什么 |
|---|---|
| 域名 | `dash.yourdomain.com`（你的子域名） |
| 源站类型 | **静态网站源站** |
| 强制 HTTPS | 建议开启（证书绑好之后再开） |

添加后列表会显示一条 **CNAME** 值，形如：

```
xinjiang-dashboard-125xxxxxxxxx.cos.ap-guangzhou.myqcloud.com
```

复制它，下一步要用。

### 5.2 去 DNS 加解析

到你的域名服务商（腾讯云 DNSPod / 阿里云 / 其他）添加记录：

| 记录类型 | 主机记录 | 记录值 |
|---|---|---|
| CNAME | `dash` | 上面复制的 CNAME 值 |

等 5~30 分钟生效。验证：

```bash
nslookup dash.yourdomain.com
# 返回的地址应该是 xxx.cos.ap-guangzhou.myqcloud.com 之类
```

### 5.3 配 HTTPS 证书

「自定义源站域名」列表 → 该域名 → **绑定证书**：

- 没有证书：点「申请腾讯云证书」→ 免费 DV 证书（1 年期，`dash.yourdomain.com`）
- 已有证书：粘贴证书内容和私钥

证书签发一般 10 分钟内。绑好后回到域名配置，打开「强制 HTTPS」。

### 5.4 验收

浏览器打开 `https://dash.yourdomain.com`，应该：
- 地址栏有小锁
- 直接显示大屏，**不是下载文件**
- 5 秒开场动画后左右面板滑入

## 六、缓存策略（可选但强烈建议）

dist 里的文件名都带 content hash（`index-B16py0WA.js`），内容变了文件名就变，所以可以放心设长缓存。

**给 `static/`、`assets/` 目录设长缓存**：
存储桶 → 文件列表 → 选中 `static/` 下的文件 → 「更多」→「设置 Header」：

```
Cache-Control: public, max-age=31536000, immutable
```

**给 `index.html` 设短缓存**（否则更新后用户看不到新版）：

```
Cache-Control: no-cache
```

## 七、防盗链（可选）

「基础配置」→「防盗链设置」→ 开启，白名单填你自己的域名。
不做也行，但被别的站盗刷流量是要花钱的。

---

## 八、费用：到底多少钱

按大陆地域标准存储、按量计费估算：

| 计费项 | 单价（约） | 你的用量 | 月成本 |
|---|---|---|---|
| 存储 | 0.099 元/GB/月 | 4MB | ≈ 0.001 元 |
| 外网下行流量 | 0.5 元/GB | 每次访问约 4MB | 1000 次访问 ≈ 2 元 |
| 请求次数 | 0.01 元/万次 | 每次访问约 40 次请求 | 1000 次访问 ≈ 0.04 元 |

**结论：没有流量基本不花钱；每天几十人看，一个月一两块钱。** 唯一要留意的是流量——被恶意刷或上热门，账单会涨，所以第七节的防盗链值得开。

新用户通常有 6 个月免费额度（50GB 存储 + 一定流量），够你测很久。

## 九、以后怎么更新

```bash
cd xinjiang-dashboard
# 改代码
npm run build
# 重新上传（会覆盖同名文件，旧 hash 文件会残留，可定期清理）
coscmd upload -r dist/ /
```

控制台方式：删掉旧的 `static/` 目录再传新的（因为文件名带 hash，不删会越堆越多）。

## 十、出问题照着这张表查

| 现象 | 原因 | 解决 |
|---|---|---|
| 打开就下载文件 | 用了默认域名 | 走第五节绑自定义域名 |
| 403 AccessDenied | 桶权限是「私有读写」 | 改成「公有读私有写」 |
| 404 但文件明明在 | 上传多套了一层 `dist/` | 桶根目录必须直接是 `index.html` |
| 白屏、控制台报 MIME 错误 | `.js` 的 Content-Type 不对 | 文件详情里把 Content-Type 改成 `application/javascript`；`.wasm` 改 `application/wasm` |
| 地图数据加载不到 | 上传时漏传了 json | 检查桶里 `assets/json/` 是否有 `china.json`、`xj-prefectures.json`、`xj-outline.json`（本项目已统一英文名，避免 COS 上的中文路径编码 404） |
| 改了代码线上没变 | 浏览器 / CDN 缓存 | Ctrl+F5 强刷；index.html 设 `no-cache` |
| 域名绑定被拒 | 域名未备案（大陆地域） | 去备案，或换中国香港地域重建桶 |
| HTTPS 打不开 / 重定向循环 | 静态网站和自定义域名两处都开了强制 HTTPS | 关掉静态网站里的那个，只留自定义域名的 |
| 访问 `/#/gdMap` 出现 404 | 路径写错 | hash 路由不用服务端重写，直接访问根域名即可，`#/gdMap` 会被浏览器处理 |

## 附：这套配置为什么不用改代码

- `vite.config.js` 里 `base: './'` → 所有资源都是相对路径，放根目录、放子目录都能跑
- 路由用的是 **hash 模式**（`#/gdMap`），`#` 后面的内容不会发到服务器 → 不需要配置「所有路径重写到 index.html」这种 Nginx/Netlify 规则
- 唯二的坑是**中文文件名**和 **MIME 类型**，见上表最后两行
